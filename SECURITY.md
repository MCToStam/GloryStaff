# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans GloryStaff, merci de ne pas créer d'Issue publique.

Envoyez plutôt un rapport privé en indiquant :

- Une description de la vulnérabilité
- Les étapes pour la reproduire
- L'impact potentiel
- Toute information utile permettant de corriger le problème

## Contact

Pour signaler une vulnérabilité, utilisez :

- GitHub Security Advisories : https://github.com/MCToStam/GloryStaff/security/advisories

ou contactez directement le mainteneur du projet.

## Processus de correction

Après réception d'un rapport :

1. Le problème sera analysé.
2. Une correction sera développée.
3. Une nouvelle version pourra être publiée.
4. Les contributeurs seront informés si nécessaire.
