> GloryStaff est un outil unique qui a pour but de faciliter le travail répétitif. Il peut être configuré très facilement et en autonomie totale !

## ✨ Fonctionnalités

- ⚙️ Configuration simple et rapide
- 🤖 Automatisation des tâches répétitives
- 🗄️ Stockage des données avec MongoDB
- 🔧 Projet open source ouvert aux contributions

---

## 📋 Prérequis

Avant de lancer le projet, assurez-vous d'avoir installé :

- [Node.js](https://nodejs.org/) (version récente recommandée)
- [MongoDB](https://www.mongodb.com/)

---

## 🚀 Installation

### 1. Cloner le dépôt

```bash
git clone https://github.com/MCToStam/GloryStaff.git
cd GloryStaff
```

### 2. Installer les dépendances

```bash
npm install
```

### 3. Configurer les variables d'environnement

Renommez le fichier :

```text
.env.exemple
```

en

```text
.env
```

Puis complétez les informations suivantes :

```env
DISCORD_TOKEN=
MONGO_URI_GLORYPROJECTS=
MONGO_URI_GLORYSTAFF=
MONGO_URI_GLORYBOT=
DISCORD_SELFBOT_TOKEN=
```

> **Important :** Une instance MongoDB fonctionnelle est nécessaire pour utiliser le bot.

---

## ▶️ Lancer le bot

Vous pouvez démarrer GloryStaff de deux façons :

Avec npm :

```bash
npm start
```

Ou directement avec Node.js :

```bash
node start.js
```
